# YouTube Clone – HTML & CSS

A responsive **YouTube homepage clone** built using **HTML and CSS**, inspired by the SuperSimpleDev HTML & CSS project.

### Features

* Responsive YouTube-style layout
* Navigation sidebar
* Search bar and header
* Video thumbnail grid
* Video titles, channel names, views, and upload information
* Responsive design for desktop, tablet, and mobile screens
* CSS Grid and Flexbox for layout
* Reusable HTML and CSS structure

### Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Responsive Design

### Purpose

This project was created as part of my **HTML & CSS practice** to improve my understanding of responsive layouts, CSS Grid, Flexbox, positioning, spacing, and component-based webpage structure.
